Windows Forms con C#: controles básicos

Guía de clase para aprender a construir aplicaciones de escritorio con .NET. Cada tema explica el concepto, muestra código listo para copiar y propone una práctica corta.

1. Tu primer proyecto

Windows Forms (WinForms) es el framework de interfaz gráfica para escritorio en Windows. Una form es la superficie visual donde se muestra información; se construye agregando controles y programando la respuesta a acciones del usuario, como clics o teclas. Se puede arrastrar y soltar desde el diseñador de Visual Studio, o crear todo por código.

Crear el proyecto

En Visual Studio: Crear un proyecto → Aplicación de Windows Forms (C#). También con la CLI:

dotnet new winforms -n MiPrimeraApp
cd MiPrimeraApp
dotnet run

Estructura

ArchivoPara qué sirve
Program.csPunto de entrada. Configura la aplicación y abre la primera form.
Form1.csTu código: eventos y lógica.
Form1.Designer.csCódigo generado por el diseñador (clase partial). No lo edites a mano.
static class Program
{
    [STAThread]
    static void Main()
    {
        ApplicationConfiguration.Initialize();
        Application.Run(new Form1());
    }
}
Todos los controles heredan de System.Windows.Forms.Control, que aporta posición, tamaño, color, fuente, foco y más de 60 eventos. Lo que aprendas de un control aplica a los demás.

3. Label y Button

Label muestra texto que el usuario no edita. Button ejecuta una acción al hacer clic. Una Label no recibe foco ni eventos de teclado.

private void btnSaludar_Click(object sender, EventArgs e)
{
    lblResultado.Text = "¡Hola, mundo!";
    btnSaludar.Enabled = false;
}
Práctica: una Label y un Button que cambian el texto al hacer clic. Después, que el botón cuente cuántos clics lleva.

4. TextBox

PropiedadUso
TextContenido escrito.
Multiline, ScrollBarsTexto de varias líneas.
PasswordChar / UseSystemPasswordCharOcultar contraseñas.
MaxLength, ReadOnlyLimitar o bloquear la edición.
PlaceholderTextTexto de ayuda cuando está vacío.
private void btnSumar_Click(object sender, EventArgs e)
{
    if (int.TryParse(txtA.Text, out int a) && int.TryParse(txtB.Text, out int b))
        lblResultado.Text = (a + b).ToString();
    else
        MessageBox.Show("Escribe números válidos.");
}
Usa siempre TryParse en lugar de Parse: el usuario escribirá cosas inesperadas y una excepción cerraría tu aplicación.

5. CheckBox, RadioButton y GroupBox

CheckBox: opción independiente (sí/no). RadioButton: una sola opción dentro de un grupo; los botones del mismo contenedor son excluyentes, por eso se agrupan en un GroupBox o Panel.

private void btnConfirmar_Click(object sender, EventArgs e)
{
    string turno = rbMatutino.Checked ? "Matutino" : "Vespertino";
    string beca  = chkBeca.Checked ? "con beca" : "sin beca";
    MessageBox.Show($"{turno}, {beca}");
}

Evento útil: CheckedChanged, que se dispara al cambiar el estado.

8. Contenedores y layout

Colocar controles con píxeles fijos se rompe al cambiar el tamaño de la ventana o la escala de pantalla. Usa estas herramientas:

HerramientaQué hace
AnchorMantiene la distancia a los bordes indicados (Top | Right…).
DockPega el control a un borde o lo rellena (Fill).
PanelAgrupa controles; puede tener barras de desplazamiento (AutoScroll).
GroupBoxAgrupa con título visible; no tiene scroll.
FlowLayoutPanelAcomoda controles en fila o columna automáticamente.
TableLayoutPanelAcomoda controles en una cuadrícula de filas y columnas.
txtNombre.Anchor = AnchorStyles.Top | AnchorStyles.Left | AnchorStyles.Right;
dgvDatos.Dock = DockStyle.Fill;
flowPanel.FlowDirection = FlowDirection.TopDown;
Regla práctica: TableLayoutPanel para el esqueleto de la pantalla, Dock para áreas grandes y Anchor para ajustes finos.

9. Eventos: cómo reacciona la interfaz

Un evento es un aviso que el control emite cuando algo ocurre; tú escribes un manejador que responde. Los controles comparten eventos de mouse (Click, MouseEnter, MouseMove…), de teclado (KeyDown, KeyPress) y de cambio de propiedad.

// Suscripción por código (el diseñador hace lo mismo)
btnGuardar.Click += btnGuardar_Click;

// Solo permitir dígitos en un TextBox
private void txtEdad_KeyPress(object sender, KeyPressEventArgs e)
{
    if (!char.IsControl(e.KeyChar) && !char.IsDigit(e.KeyChar))
        e.Handled = true; // descarta la tecla
}

El parámetro sender es el control que originó el evento; e trae datos específicos. Un mismo manejador puede atender varios controles.

13. Ejemplo completo: registro de alumnos

Crea esta interfaz solo por código para entender qué hace el diseñador. Pega el código en Form1.cs y deja Program.cs como está.

public partial class Form1 : Form
{
    readonly TextBox txtNombre = new() { PlaceholderText = "Nombre", Dock = DockStyle.Top };
    readonly ComboBox cboCarrera = new() { DropDownStyle = ComboBoxStyle.DropDownList, Dock = DockStyle.Top };
    readonly Button btnAgregar = new() { Text = "Agregar", Dock = DockStyle.Top };
    readonly ListBox lstAlumnos = new() { Dock = DockStyle.Fill };

    public Form1()
    {
        Text = "Registro";
        Size = new Size(360, 380);
        cboCarrera.Items.AddRange(new object[] { "Sistemas", "Industrial" });
        cboCarrera.SelectedIndex = 0;
        btnAgregar.Click += Agregar;
        // Dock se apila al revés: el último agregado queda arriba
        Controls.AddRange(new Control[] { lstAlumnos, btnAgregar, cboCarrera, txtNombre });
    }

    void Agregar(object? s, EventArgs e)
    {
        if (string.IsNullOrWhiteSpace(txtNombre.Text))
        {
            MessageBox.Show("Escribe un nombre.");
            return;
        }
        lstAlumnos.Items.Add($"{txtNombre.Text} - {cboCarrera.Text}");
        txtNombre.Clear();
        txtNombre.Focus();
    }
}
Retos: validar que no haya nombres repetidos; agregar un botón para eliminar el elemento seleccionado; guardar la lista en un archivo con SaveFileDialog.

14. Buenas prácticas

  • Nombra los controles con prefijo y significado: txtNombre, btnGuardar, cboCarrera. Evita textBox1.
  • Separa la lógica de la interfaz: pon cálculos y reglas en clases aparte y deja los eventos solo para coordinar.
  • Valida la entrada antes de usarla (TryParse, IsNullOrWhiteSpace).
  • No bloquees la interfaz: para tareas largas usa async/await; una operación pesada en un evento congela la ventana.
  • Liberar recursos: usa using con diálogos, archivos y conexiones.
  • Diseña para escalar: Dock, Anchor y TableLayoutPanel en lugar de posiciones fijas.
  • Accesibilidad: define TabIndex coherente, atajos con & en el texto ("&Guardar") y AcceptButton.
